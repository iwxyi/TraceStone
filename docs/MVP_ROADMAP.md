# TraceStone MVP 迭代计划

## 里程碑

| 阶段 | 目标 | 主要交付 |
| --- | --- | --- |
| M1 | 可记录 | 日记编辑、自动草稿、本地保存、溪石主题、基础设置 |
| M2 | 可洞察 | AI 修复、今日洞察、摘要标签、塑石建议 |
| M3 | 可行动 | 塑石任务、提醒、打卡、完成率、历史关联 |
| M4 | 可检索 | 本地记忆库、向量嵌入、语义搜索、成长陪伴问答 |
| M5 | 可回顾 | 周/月总结、日历、时间线、统计图表 |
| M6 | 可迁移 | WebDAV 备份恢复、Markdown + JSON 导出、自定义 AI Key |
| M7 | 可商业化 | 账号、会员、额度统计、支付入口 |

## P0 功能拆分

| 模块 | 任务 | 验收标准 |
| --- | --- | --- |
| 日记 | 自动创建今天/昨天日记 | 按打开时段进入正确日期草稿 |
| 日记 | 文本编辑与自动保存 | 崩溃或退出后可恢复草稿 |
| 日记 | 图片输入与压缩 | 多图可附加，上传前已压缩 |
| 日记 | 语音转文字入口 | 可获得可编辑文本 |
| AI | 原汁原味修复 | 只修错字、标点、明显语病 |
| AI | 今日洞察包 | 200 字以内读后感 + 1 条塑石建议 |
| AI | 记忆更新 | 摘要、关键词、情绪、人物写入本地 |
| 塑石 | 一键采纳建议 | 生成可编辑任务，可设置提醒 |
| 塑石 | 列表展示 | 进行中和已完成任务按时间排序 |
| 陪伴 | 多轮问答 | 回答能引用检索到的个人历史 |
| 回顾 | 周/月/年总结 | 周期结束后可生成总结文本 |
| 搜索 | 语义查询 | 自然语言可检索相关日记 |
| 关系 | 实体识别与别名 | 可识别人名并绑定昵称 |
| 设置 | WebDAV | 可配置、备份、恢复 |
| 设置 | 自定义 AI | 可配置 Key 和端点 |
| 设置 | 日记锁 | 可设置独立密码或生物识别 |
| 设置 | 离线模式 | 无网络可编辑和查看本地内容 |

## 暂缓项

| 功能 | 原因 |
| --- | --- |
| 关系图谱可视化 | 依赖足够关系数据，MVP 可先做列表与详情 |
| 复杂词云图表 | 可在总结文本稳定后再做视觉增强 |
| 自定义字体完整市场 | 初期只保留字体缩放与少量内置字体 |
| 高级动效 | 不阻塞核心记录与洞察闭环 |

## 推荐开发顺序

| 顺序 | 内容 |
| --- | --- |
| 1 | ObjectBox 数据模型与本地仓储 |
| 2 | 日记编辑页、草稿、附件 |
| 3 | AI Client 抽象与自定义端点配置 |
| 4 | AI 修复、洞察、塑石建议协议 |
| 5 | 塑石任务与打卡 |
| 6 | 本地嵌入模型与语义搜索 |
| 7 | 成长陪伴问答 |
| 8 | WebDAV 备份恢复 |
| 9 | 周/月总结与统计 |
| 10 | 会员和额度统计 |
