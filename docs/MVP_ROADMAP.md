# 拾年·Shinen MVP 迭代计划

产品主题：记录与成长。MVP 不做打卡、任务系统、连续天数和完成率；所有成长相关功能都应保持轻松、可选择、不施压。

## 里程碑

| 阶段 | 目标 | 主要交付 |
| --- | --- | --- |
| M1 | 可记录 | 日记编辑、自动草稿、本地保存、溪石主题、基础设置 |
| M2 | 可洞察 | AI 修复、今日分析、摘要标签、成长线索 |
| M3 | 可看见变化 | 成长线索收藏、微小变化记录、历史关联 |
| M4 | 可检索 | 本地记忆库、向量嵌入、语义搜索、树洞问答 |
| M5 | 可看时光 | 周/月总结、日历、时间线、统计图表 |
| M6 | 可迁移 | WebDAV 备份恢复、Markdown + JSON 导出、自定义 AI Key |
| M7 | 可商业化 | 账号、会员、额度统计、支付入口 |

## P0 功能拆分

| 模块 | 功能 | 验收标准 |
| --- | --- | --- |
| 日记 | 自动创建今天/昨天日记 | 按打开时段进入正确日期草稿 |
| 日记 | 文本编辑与自动保存 | 崩溃或退出后可恢复草稿 |
| 日记 | 图片输入与压缩 | 多图可附加，上传前已压缩 |
| 日记 | 语音转文字入口 | 可获得可编辑文本 |
| AI | 原汁原味修复 | 只修错字、标点、明显语病 |
| AI | 今日分析包 | 200 字以内读后感 + 1 条低压力成长线索 |
| AI | 记忆更新 | 摘要、关键词、情绪、人物写入本地 |
| 成长线索 | 收藏建议 | 生成可编辑的一小步，不设置强制截止和完成要求 |
| 成长线索 | 列表展示 | 展示收藏的一小步和自然记录的微小变化 |
| 树洞 | 多轮问答 | 回答能引用检索到的个人历史 |
| 时光 | 周/月/年总结 | 周期结束后可生成总结文本 |
| 搜索 | 语义查询 | 自然语言可检索相关日记 |
| 关系 | 实体识别与别名 | 可识别人名并绑定昵称 |
| 设置 | WebDAV | 可配置、备份、恢复 |
| 设置 | 自定义 AI | 可配置 Key 和端点 |
| 设置 | 日记锁 | 可设置独立密码或生物识别 |
| 设置 | 离线模式 | 无网络可编辑和查看本地内容 |

## 暂缓项

| 功能 | 原因 |
| --- | --- |
| 关系图谱可视化 | 依赖足够关系数据，MVP 可先做列表与详情 |
| 复杂词云图表 | 可在总结文本稳定后再做视觉增强 |
| 自定义字体完整市场 | 初期只保留字体缩放与少量内置字体 |
| 高级动效 | 不阻塞核心记录与洞察闭环 |

## 推荐开发顺序

| 顺序 | 内容 |

| 4 | AI 修复、洞察、成长线索协议 |
| 5 | 成长线索收藏与微小变化记录 |
| 6 | 本地嵌入模型与语义搜索 |
| 7 | 树洞问答 |
| 8 | WebDAV 备份恢复 |
| 9 | 周/月总结与统计 |
| 10 | 会员和额度统计 |
