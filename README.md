# 拾年 · Shinen

**拾起时光的碎片，记录、沉淀、成长。**

我们相信，成长不是脱胎换骨的奇迹，而是每天沉淀一层、再沉淀一层的累积。
就像河床的岩层，每一层都记录着一个时代。你的每一天，也在记录着你的人生。

## 什么是拾年

拾年，是你和自己的对话。
它把平凡日子里那些值得留下的瞬间，轻轻收起来。
多年以后，你还能沿着来时的足迹，看见自己是怎样一步步走到今天的。

## 记录，本该如此自然

打开拾年，这一天已经为你准备好了。
天气、地点、日期，安静地等在页面上，你只需要写下此刻心中所想。

一句话也好，一段话也好。
说到哪里算哪里。语音会帮你整理成文字。看到什么想留下的，拍下来就好，照片会自动缩成合适的大小，AI 也会帮你识别那一刻的情境。

你说的话，永远是你的话。AI 只会帮你拂去错别字的尘埃，不改一字一句的语气。因为真实，比完美更珍贵。

## 被你遗忘的自己，它替你记得

每一次记录，都在沉淀。每一次沉淀，都在累积。

慢慢地，你会发现，拾年开始懂你。
它记得你三个月前的那个困惑，所以在今天你再次徘徊时，它会轻轻提醒：你上次是这样走过来的，这次或许也可以试试。
它看见了你自己都没注意到的改变，所以它会告诉你：半年前这件小事让你难过很久，现在你已经可以平静地回头看它了。

这不是监督，也不是敦促。
这是一个安静的同行者，在你需要的时候，递上一块石头，上面刻着你走过的路，也刻着你即将走的方向。

## 那些被你拾起的时光，终将发光

当你的日记一天天厚起来，拾年会帮你把这些碎片编织成册。

周报、月报、年报，不是冷冰冰的统计数字，而是你情绪的潮汐、你关注点的流转、你人际关系的温度。
你会看见，哪些模式在悄悄重复，哪些成长在悄然发生，哪些人一直在你身边，哪些自己已经被你远远地留在了过去。

你还可以随时提问：

- 我这一年提到的最多的是什么？
- 我和那个人的关系是怎么变化的？
- 我第一次去新加坡是什么时候？
- 去年杭州的梅花什么时候开？

所有回答，都来自你自己写下的文字。
拾年只是帮你看见，那些你已经拥有、却未曾察觉的答案。

## 你的时光，只属于你

你写下的每一个字，都只存放在你的设备里。
如果你想多一份安心，可以连接自己的云盘进行备份，那是你私人的领地，拾年不会触碰。

如果你有自己的 AI 密钥，也可以接进来，让整个过程完全在你的掌控之中。

你的时光，从来就应该由你自己保管。

## 最后

拾年不承诺让你变成另一个人。
它只是在你每天走过的小路上，在路边的草丛里，拾起那些容易被风吹散的碎片。
然后，在你需要的时候，把它们交还给你。

你握着这些碎片，才会发现：

原来我已经走了这么远。
原来我的每一天，都在发光。

# 技术介绍

## 核心能力

| 模块 | 说明 | 优先级 |
| --- | --- | --- |
| 日记记录 | 自动创建日记页，支持文本、语音、图片、天气与位置元数据 | P0 |
| AI 分析 | 保存后进行原汁原味修复、今日分析、记忆更新与成长线索 | P0 |
| 成长线索 | 将 AI 建议收藏为可轻轻尝试的一小步，不做打卡或完成率 | P0 |
| 树洞 | 基于个人记忆库的多轮问答与引导式反思 | P0 |
| 时光 | 周/月/年总结、时间线、日历与趋势统计 | P0/P1 |
| 语义搜索 | 本地向量检索，支持自然语言查询与筛选 | P0 |
| 人际关系 | 自动识别人名、别名管理、互动记录与关系查询 | P0/P1 |
| 账号体系 | 手机号验证码登录、密码登录、账号资料与会员状态入口；不承载日记同步 | P1 |
| 数据主权 | WebDAV 备份恢复、自定义 AI Key、本地优先与离线可用 | P0 |
| 个性化 | 日夜间模式、主题皮肤、日记锁、提醒、导出与字体缩放 | P0/P1 |

## 技术选型

| 层级 | 技术 |
| --- | --- |
| 客户端 | Flutter |
| 本地数据库 | ObjectBox |
| 向量检索 | ObjectBox Vector Search |
| 本地嵌入 | all-MiniLM-L6-v2 TFLite，384 维向量 |
| 语音识别 | 平台原生 API 或第三方 SDK |
| 图片压缩 | flutter_image_compress |
| WebDAV | webdav_client |
| 后端边界 | 仅账号、会员、计费、使用统计，不接触日记明文 |

```bash
flutter pub get
flutter run
```

### 测试

```bash
flutter test
```

### 代码检查

```bash
flutter analyze
```

## 隐私与数据原则

| 原则 | 要求 |
| --- | --- |
| 本地优先 | 日记明文、记忆库、向量索引优先存储在用户设备 |
| 用户主权 | 支持 WebDAV 备份恢复与可读 Markdown + JSON 导出 |
| AI 可替换 | 支持官方额度，也支持用户自定义 Key 与端点 |
| 后端最小化 | 后端不保存、不分析、不接触日记明文；日记同步只走用户自己的 WebDAV |
| 原汁原味 | AI 修复只改错别字、标点与明显语病，不重写用户风格 |
